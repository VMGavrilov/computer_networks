# IPv4

В рамках лабораторной работы по дисциплине «Компьютерные сети» были выполнены расчёты IP‑адресации для проектирования сетей. Целью расчётов было научиться правильно выбирать маску подсети в зависимости от количества узлов и сегментов. Для этого применялись базовые принципы двоичной арифметики: расчёт необходимого числа бит на узлы, число бит на подсети и определение итоговой маски.

В первой задаче была рассчитана адресация для пяти зданий с разным количеством устройств (от 15 до 25). На основе анализа максимального числа узлов был выбран оптимальный префикс подсети /27.
Во второй задаче требовалось спроектировать сеть из 20 подсетей, каждая из которых должна содержать не менее 10 рабочих станций. С помощью метода деления битов вычислена общая длина префикса — /25.

Работа закрепила навыки расчета адресного пространства и показала практическое применение теории CIDR при проектировании реальных сетевых топологий.
