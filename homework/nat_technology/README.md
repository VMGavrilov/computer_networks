## Цель работы
Изучить принципы трансляции адресов, настроить динамический PAT для выхода в интернет через один IP и статический NAT для доступа к внутреннему серверу извне.

## Топология
Сеть офиса (3 ПК, веб-сервер, коммутатор Catalyst 2960, роутер Cisco 1841) и провайдерская сеть (роутер Cisco 1841, сервер с белым IP). Внутренняя сеть разделена на две VLAN (пользователи и сервер) с помощью trunk-порта.

## Выполненные задачи
1.  Настроен коммутатор (созданы VLAN, настроен транк).
2.  Настроены роутеры (IP-адреса интерфейсов, маршруты по умолчанию).
3.  Настроена раздача IP-адресов (DHCP или вручную).
4.  Реализован динамический PAT (выход в сеть под общим IP провайдера).
5.  Настроен статический NAT (проброс порта 80 к веб-серверу).

Работа закрепила навыки проектирования сетей с ограниченным числом внешних IP и сокрытия внутренней структуры.
