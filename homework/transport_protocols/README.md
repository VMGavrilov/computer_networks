## Суть работы
Изучено устройство транспортного уровня TCP/IP. Цель — освоить принципы работы UDP и TCP, их отличия, механизмы надежности и области применения.

## Выполненные задачи
1.  Изучение структуры заголовков TCP и UDP.
2.  Анализ различий между протоколами (установление соединения, нумерация байтов, подтверждение доставки).
3.  Освоение механизмов управления перегрузкой в TCP (Slow Start, Fast Retransmit и др.).
4.  Понимание назначения флагов TCP (SYN, ACK, FIN, RST).

## Итог
Выбор протокола зависит от требований приложения. UDP выбирают для скорости (видео, DNS), TCP — для гарантированной доставки и целостности данных.
