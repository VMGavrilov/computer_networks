## Суть работы
Выполнены расчеты IP-адресации для проектирования сетей. Цель — научиться выбирать маску подсети по количеству узлов и сегментов, используя принципы двоичной арифметики.

## Задачи
1.  **Задача 1:** Расчет адресации для 5 зданий (от 15 до 25 устройств). На основе максимального числа узлов выбран оптимальный префикс `/27`.
2.  **Задача 2:** Проектирование сети из 20 подсетей (минимум по 10 ПК в каждой). Вычислен общий префикс `/25`.

Работа закрепила навыки расчета адресного пространства и показала применение теории CIDR на практике.
