## Цель
Изучить принципы проектирования сетей, освоить Cisco Packet Tracer и научиться выбирать оборудование.

## Выполненные схемы
В рамках работы построены три топологии ЛВС для демонстрации разных подходов к организации сети:

*   **Схема 1:** Сеть на базе коммутатора и роутеров. ПК подключены к маршрутизаторам, объединенным общим свитчем. Позволяет эффективно сегментировать трафик.
*   **Схема 2:** Сеть из концентраторов (Hub) и роутеров. Классическая модель с разделением трафика на втором уровне модели OSI.
*   **Схема 3:** Смешанная сеть с кольцевой структурой. Наличие двух путей для каждого узла повышает отказоустойчивость.
