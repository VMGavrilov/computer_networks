# Протокол DHCP

## В рамках лабораторной работы по дисциплине «Компьютерные сети» были выполнены три схемы топологии сетей. Схемы демонстрируют различные подходы к организации локальных вычислительных сетей (ЛВС) с использованием сетевого оборудования: маршрутизаторов, коммутаторов и концентраторов.

Схема 1: сеть на основе коммутатора (Switch) и нескольких маршрутизаторов. В данной схеме компьютеры подключены непосредственно к маршрутизаторам, которые в свою очередь объединены через центральный коммутатор. Такая архитектура позволяет эффективно сегментировать сеть и управлять трафиком между подсетями.

Схема 2: сеть на основе концентраторов (Hub) и маршрутизаторов. Концентраторы объединяют несколько сегментов сети, а маршрутизаторы обеспечивают связь между ними. Эта схема демонстрирует классическую модель построения ЛВС с разделением трафика на уровне второго уровня модели OSI.

Схема 3: смешанная сеть из коммутаторов и маршрутизаторов, соединенных кольцевой структурой. Данная схема иллюстрирует более сложную архитектуру, где каждый узел имеет два пути для связи с другими узлами, что повышает отказоустойчивость сети.

## Цель выполнения схем:
Изучить принципы проектирования компьютерных сетей;
Освоить работу с симулятором Cisco Packet Tracer;
Научиться правильно выбирать оборудование для различных задач.
