# Схемы компьютерных сетей

## Задание: составить схемы для лабораторных работ по дисциплине «Компьютерные сети».

# Описание схем:
Схема 1 — сеть с коммутатором и маршрутизаторами.
Используются устройства: ПК, коммутатор (Switch0), маршрутизаторы (Router0–4).
Маршрутизаторы соединены между собой через коммутатор, а к каждому из них подключено по одному или два компьютера.
Схема 2 — сеть на основе концентраторов (Hub) и маршрутизаторов.
Используются устройства: ПК, концентраторы (Hub-PT Hub0, Hub-PT Hub1, Hub-PT Hub2), маршрутизаторы (Router1–5).
Концентраторы объединены в единую топологию, к ним подключены маршрутизаторы и компьютеры.
Схема 3 — смешанная сеть с использованием коммутаторов и маршрутизаторов.
Используются устройства: ПК, коммутаторы (Sw itch0, Sw itch1, Sw itch2, Sw itch3, Sw itch4), маршрутизаторы (Router1, Router2, Router3).
Коммутаторы объединяют группы компьютеров, а маршрутизаторы обеспечивают связь между сегментами сети.
Цель работы:

Изучить принципы построения локальных вычислительных сетей, освоить работу с сетевыми устройствами (коммутаторы, маршрутизаторы, концентраторы) и закрепить навыки проектирования простых топологий.
