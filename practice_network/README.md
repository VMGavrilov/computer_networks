# Расчёт IP-адресации

## Суть работы

В рамках лабораторной работы по дисциплине «Компьютерные сети» были выполнены расчёты IP‑адресации с использованием технологии VLSM (Variable Length Subnet Mask).

Целью работы было научиться правильно делить сеть на подсети, используя минимально возможную маску для эффективного использования адресного пространства. Для этого применялись знания двоичной арифметики и принципов CIDR.

**Суть работы:**
Выполнены расчеты IP-адресации с использованием технологии VLSM (Variable Length Subnet Mask). Цель — научиться делить сеть на подсети с минимальной маской для эффективного использования адресов.

**Выполненные задачи:**
1.  Деление сети класса C (`/24`) на несколько подсетей с разным числом хостов.
2.  Выбор оптимальной маски исходя из максимального числа узлов в сегменте.
3.  Определение диапазонов IP-адресов для каждого сегмента.

Работа закрепила навыки проектирования сетей с учетом реальных потребностей (от маленьких серверных до крупных рабочих групп).
## Выполненные задачи:
Деление единой сети класса C (/24) на несколько подсетей с разным количеством хостов в каждой.
Выбор оптимальной маски подсети исходя из максимального числа узлов в сегменте.
Определение диапазонов IP‑адресов для каждого сегмента.

Работа закрепила навыки проектирования сетей с учётом реальных потребностей организации — от выделения небольших сегментов для серверных комнат до крупных подсетей для рабочих групп.
