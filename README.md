## Кратко о проделанных работах
*   **DHCP:** Настраивал автоматическую выдачу IP-адресов для компьютеров, чтобы не прописывать их вручную.
*   **TCP/UDP:** Разбирал, чем отличаются протоколы передачи данных (один для скорости, второй — для надежности).
*   **NAT:** Учился выпускать локальные компьютеры в интернет через один внешний IP-адрес и пробрасывать порты.
*   **VLAN:** Создавал виртуальные сети, чтобы разделить трафик разных отделов на одном коммутаторе.
*   **Маршрутизация:** Настраивал роутеры Cisco, чтобы они передавали пакеты между разными сетями.
*   **Лабораторные:** Собирал рабочие схемы в Cisco Packet Tracer и проверял их работу с помощью ping.
*   **Wireshark:** Анализировал реальный сетевой трафик, искал и разбирал конкретные пакеты.
*   **IP-адресация:** Считал маски и делил сети на подсети (VLSM) для экономии адресов.
*   **DNS:** Настраивал сервер, чтобы компьютеры находили сайты по именам, а не по цифровым адресам.

## Инструменты
