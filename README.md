🛠️ Дисциплина: Компьютерные сети

**Что в репозитории:**
*   `presentations/` — презентации к семинарам.
*   `screens/` — скриншоты.
*   `report.md` — конспекты и схемы.

**Содержание:**
*   **DHCP:** Протокол динамического конфигурирования хостов.
*   **TCP/UDP:** Транспортный уровень TCP/IP.
*   **NAT:** Трансляция сетевых адресов (статический, динамический, PAT).
*   **VLAN:** Виртуальные локальные сети.
*   **Маршрутизация:** Настройка роутеров Cisco.
*   **Лабораторные:** Практические работы в Cisco Packet Tracer.

**Инструменты:** Cisco Packet Tracer, Markdown, Git / GitHub.
