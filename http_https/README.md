## Содержание
В работе разобраны базовые понятия протокола HTTP:
- определения HTTP, HTTPS, клиент-серверной модели и идемпотентности;
- детальный разбор HTTP-запроса (методы, заголовки, тело) и ответа (статус-коды, Location);
- примеры составления запросов для типовых операций (CRUD) с товарами.
