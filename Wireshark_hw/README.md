**Суть работы:**
В ходе лабораторной работы выполнен анализ сетевого трафика в Wireshark. Цель — освоить интерфейс и базовый разбор пакетов.

**Что изучено:**
*   **Список кадров:** таблица перехваченных пакетов (время, источник, протокол).
*   **Детализация пакета:** расшифровка заголовков выбранного кадра.
*   **Содержимое пакета:** данные в шестнадцатеричном виде.

Работа закрепила навыки визуального анализа протоколов (UDP, TCP, DNS, NBTNS) и сетевых запросов.
