# Анализ трафика в Wireshark

##Суть работы

В рамках лабораторной работы по дисциплине «Компьютерные сети» было выполнено задание на анализ сетевого трафика с помощью программы Wireshark.

Целью работы являлось освоение интерфейса и базовых возможностей анализа пакетов. Для этого был открыт файл захвата (или запущена запись живого трафика), а затем изучены следующие элементы:

Список кадров — таблица, отображающая все перехваченные пакеты с указанием времени, источника, назначения, протокола и краткого описания содержимого;
Детализация пакета — подробная расшифровка заголовков выбранного кадра (например, кадры №751 и 760 выделены на скриншоте);
Содержимое пакета — шестнадцатеричное представление данных из выбранного кадра.

Работа закрепила навыки визуального анализа структуры сетевых протоколов, таких как UDP, TCP, DNS, NBTNS и другие, которые видны в списке кадров. На основе предоставленного изображения были рассмотрены примеры запросов к локальным службам именования (NBTNS, LLMNR) и обмена данными через протоколы транспортного уровня.
