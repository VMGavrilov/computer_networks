# MAC-адрес

**Цель работы:** Изучить структуру MAC-адреса, выявить причины конфликтов адресов и освоить методы их устранения на практике.

**Ключевые понятия:**
*   **Структура:** 48-битный уникальный идентификатор (код производителя + серийный номер). Пример: `00:1A:2B:3C:4D:5E`.
*   **Типы:** Unicast (один узел), Multicast (группа), Broadcast (`FF:FF:FF:FF:FF:FF`).

**Конфликт MAC-адресов** возникает, когда два устройства имеют одинаковый адрес. Из-за этого коммутатор не может понять, куда отправлять данные, что вызывает сбои в сети.

**Методы решения:**
1.  Найти дубликат через таблицу MAC-адресов коммутатора.
2.  Сменить MAC-адрес вручную или сгенерировать новый.
3.  Проверить обновление таблицы коммутатора.

Работа закрепила навыки анализа таблиц коммутации и настройки физических параметров оборудования.
