# MAC-адрес

В рамках лабораторной работы по дисциплине «Компьютерные сети» были изучены физические адреса (MAC-адреса) и рассмотрены причины возникновения конфликтов в сетях.

## Целью работы было:

Изучить структуру MAC‑адреса, его назначение и типы;
Выявить типичные ошибки при настройке сетевых устройств, приводящие к конфликту адресов;
Освоить методы диагностики и устранения таких конфликтов на практике с помощью таблицы коммутации коммутатора.

## Ключевые понятия:

Структура: 48‑битный уникальный идентификатор устройства состоит из кода производителя (OUI) и серийного номера. Пример записи — 00:1A:2B:3C:4D:5E.
Типы: Unicast (один конкретный узел), Multicast (группа узлов), Broadcast (FF:FF:FF:FF:FF:FF).

Конфликт MAC‑адресов возникает, когда два или более устройства имеют одинаковый физический адрес. Это приводит к тому, что коммутатор не может корректно определить порт назначения для передачи данных, вызывая нестабильность связи или полный разрыв соединения.

Методы решения проблемы:

Найти устройство с дублирующимся адресом через таблицу MAC‑адресов коммутатора.
Сменить MAC‑адрес вручную либо автоматически сгенерировать новый (в зависимости от операционной системы или типа виртуальной машины).
Проверить обновление таблицы коммутатора после изменения.

Работа закрепила навыки анализа таблиц коммутации и настройки физических параметров сетевого оборудования.
