# NAT in Cisco

В рамках лабораторной работы по дисциплине «Компьютерные сети» была смоделирована и настроена сеть с использованием технологии NAT (Network Address Translation).

## Целью работы было:

Изучить принципы трансляции сетевых адресов;
Освоить настройку динамического NAT (PAT — Port Address Translation) для предоставления доступа локальных компьютеров к Интернету через один внешний IP-адрес;
Научиться настраивать статический NAT для проброса портов, чтобы обеспечить доступ из внешней сети к внутреннему серверу.
Описание топологии

## Была создана модель сети предприятия со следующими компонентами:

Локальная сеть офиса: 3 рабочих компьютера, веб‑сервер, коммутатор Cisco Catalyst 2960, маршрутизатор Cisco 1841.
Провайдерская сеть: маршрутизатор Cisco 1841 и сервер с белым IP‑адресом.

Локальные устройства были разделены на две VLAN: одна для пользователей, другая для сервера. Связь между ними обеспечивал trunk-порт на коммутаторе.

## Выполненные задачи
Настроен коммутатор: созданы VLAN для сегментов сети, настроено объединение интерфейсов в транк.
Настроены маршрутизаторы: назначены адреса внутренним и внешним интерфейсам, прописаны маршруты по умолчанию.
Выполнена настройка DHCP или ручная раздача IP‑адресов всем устройствам.
Реализован динамический PAT: все внутренние компьютеры получили возможность выходить во внешнюю сеть под одним общим IP‑адресом провайдера.
Настроен статический NAT: открыт доступ к локальному веб‑серверу извне по порту 80.

Работа закрепила навыки проектирования сетей с ограниченным количеством внешних IP‑адресов и обеспечения безопасности за счет сокрытия внутренней структуры сети от внешнего мира.
